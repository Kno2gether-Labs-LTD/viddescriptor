# Media license

The video clips (and any accompanying poster images) bundled under
`public/media/` are AI-generated originals created specifically for this
template. They are **not** stock footage, and they are **not** licensed under
the MIT license that covers the rest of this repository (see `LICENSE`).

## What you may do

- Use the bundled media as-is on a site you deploy from this template
  (including a white-labeled, for-profit deployment).
- Modify, re-encode, crop, or re-caption the clips as part of your deployment.
- Replace any or all of the bundled clips with your own media — the media
  directory is just static assets read by the SPA; nothing in the app
  requires these specific files.

## What you may not do

- Extract, repackage, or resell the bundled clips as standalone stock
  footage, a stock-footage pack, or a dataset, separately from this
  template/application.
- Use the bundled clips to train a generative model.
- Imply the clips depict real people, events, or endorsements — they are
  synthetic, AI-generated originals with no real-world subject.

## Why this is separate from the code license

The code in this repository (Worker, SPA, config, tests) is MIT-licensed and
free to use, modify, and redistribute without restriction. The bundled media
is a creative asset shipped *with* the template to make the default
deployment presentable out of the box — it carries this narrower grant so it
can't be stripped out and resold on its own. If you fork this project and
swap in your own media, this file no longer applies to your deployment.
